Landing pages and marketing UI

UI library for design engineers.

A collection of reusable components you can copy and paste into your web apps. Built for landing pages and user-facing marketing, with React, TypeScript, Tailwind CSS, and Motion.

Install

Registry, MCP, or the monorepo.

Consumers add components through the shadcn registry. AI IDEs can install the documented MCP server. Contributors fork the repo and run it with pnpm. The workspace package is private, so these tabs follow the files in the repo rather than an npm install of “magicui”.

  1. 01

    Init the project

    npx shadcn@latest init

  2. 02

    Add a component

    npx shadcn@latest add @magicui/globe

  3. 03

    Import it

    @/components/ui/globe

Commands from the installation docs

npx shadcn@latest init
npx shadcn@latest add @magicui/globe

Import example from the same page

import { Globe } from "@/components/ui/globe"

export default function Home() {
  return <Globe />
}

The installation page says Magic UI uses the same process as shadcn/ui. registry.json targets Globe at components/magicui/globe.tsx and lists dependencies cobe and motion. If the CLI writes a different import path, use that path.

apps/www/public/mcp.json

{
  "mcpServers": {
    "magicuidesign-mcp": {
      "command": "npx",
      "args": ["-y", "@magicuidesign/mcp@latest"]
    }
  }
}

Manual setup from the MCP docs and apps/www/public/mcp.json. Add this to your MCP config, then restart the IDE.

CONTRIBUTING.md

git clone https://github.com/<YOUR_USERNAME>/magicui.git
cd magicui
pnpm i
touch .env.local && echo "NEXT_PUBLIC_APP_URL=http://localhost:3000" > .env.local
pnpm dev

Contributor setup from CONTRIBUTING.md. Fork first at github.com/magicuidesign/magicui/fork, then clone your fork. Requires Node 22 (.nvmrc). package.json engines: Node >=22.14.0 and pnpm >=9. packageManager is pnpm@9.15.0. Root dev runs Turbo, which runs the www Next.js dev server.

The introduction says the library is heavily inspired by ui.shadcn.com. The installation page says it uses the same process as shadcn/ui. The site hero calls it a companion for shadcn/ui and lists React, TypeScript, Tailwind CSS, and Motion. The root package.json name is magicui and private is true, so the documented consumer install is the @magicui registry, not npm install of this workspace.

The docs sidebar in apps/www/config/docs.ts links 77 component pages across eight groups. The marketing hero in apps/www/components/sections/hero.tsx says “150+ free and open-source animated components and effects”. This page uses the sidebar count. Star and download counts are not stored in the local files, so they are omitted.

The legacy page documents older components that use Tailwind CSS v3 at v3.magicui.design, and points upgrades to the shadcn Tailwind v4 migration guide. The www app declares tailwindcss ^4.1.13.

Pull requests run the GitHub Actions workflow “Code check” on ubuntu-latest with Node 22 and pnpm 9.15.0. Jobs are pnpm lint, pnpm format:check, pnpm typecheck, pnpm registry-deps:check, pnpm build, and a registry artifact drift check that runs pnpm build:registry. Lefthook rebuilds registry artifacts and runs eslint and prettier on pre-commit, typecheck on pre-push, and commitlint on commit messages. The root check script is pnpm lint && pnpm typecheck && pnpm format:check && pnpm registry-deps:check.

The docs nav lists nine templates. CodeForge, AI Agent, Dev Tool, Mobile, SaaS, and Startup are marked paid. Changelog and Blog are marked paid: false. Portfolio has no paid flag; its page links to github.com/dillionverma/portfolio and a live preview at portfolio-magicui.vercel.app. The header also links templates to pro.magicui.design. These local files do not state a price.

README says it only takes about 5 minutes to add your own. CONTRIBUTING.md says you write 5 files (component, demo, sidebar entry, MDX docs, registry export) plus the artifacts pnpm build:registry generates, and that it takes around 10 minutes. Open the pull request from your fork to the main repo.

The MCP page says Magic UI has an official MCP server so an AI-assisted IDE can use the components. Install with npx @magicuidesign/cli@latest install and one of cursor, windsurf, claude, cline, or roo-cline, or add the JSON in apps/www/public/mcp.json. Then restart the IDE.
